REST API Reference

Programmatically upload images, run CLIP zero-shot caption matching, and retrieve classification probabilities via RESTful HTTP endpoints.

POST /api/caption/
Multipart Form

Accepts an image file, runs OpenAI CLIP embedding cross-attention against candidate captions, and returns the top predicted caption and probability distribution.

Request Parameters (Form-Data):
Parameter Type Required Description
image File (Binary) Required Image file (JPG, PNG, WEBP, GIF).
custom_candidates String / JSON Array Optional Custom candidate sentences separated by newlines or JSON array of strings.
save_to_db Boolean ('true'/'false') Optional Whether to persist the record in database. Default: true.
Example Invocations:
curl -X POST http://127.0.0.1:8000/api/caption/ \
  -F "image=@photo.jpg" \
  -F "custom_candidates=A golden retriever in a field
A cat sleeping on a sofa"
import requests

url = "http://127.0.0.1:8000/api/caption/"
files = {"image": open("photo.jpg", "rb")}
data = {"custom_candidates": "A dog running\nA cat resting"}

response = requests.post(url, files=files, data=data)
print(response.json())

GET /api/history/
JSON Query

Retrieves a list of recent image caption records.

Query Parameters:
  • limit (integer, optional, default: 20): Maximum number of records to return.
Example cURL Request:
curl http://127.0.0.1:8000/api/history/?limit=10
Example JSON Response:
