How CLIP Captioning Works
Visual Vision Transformer (ViT)

The image is broken into 32x32 pixel patches and encoded into a high-dimensional continuous latent representation vector using OpenAI's Vision Transformer.

Text Semantic Embedding

Each candidate sentence is passed through CLIP's Text Transformer to create corresponding semantic text embedding vectors in the shared multi-modal space.

Cosine Similarity & Softmax

Normalized dot products compute cross-modal cosine similarity. Softmax outputs normalized probability distribution over candidate descriptions.
